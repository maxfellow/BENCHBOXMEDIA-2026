# Bench Box Media website

Static website: 69 pages, each in its own folder (`films/index.html`, `services/index.html`, ...).
Upload the **contents of this folder** to the root of your GitHub repository (not the folder itself).

## Folders
- `videos/` – all 39 films (web-compressed MP4)
- `posters/` – film thumbnails
- `logos/` – client and media partner logos
- `creatives/` – social media creatives
- `sitemap.xml`, `robots.txt`, `404.html`, `favicon.svg`, `og-image.jpg`

## Go live on Vercel (recommended)
1. vercel.com → Add New → Project → import this GitHub repo.
2. Framework preset: **Other**. No build command. Output directory: leave empty.
3. Deploy, then Settings → Domains → add `benchboxmedia.com`.

## Or GitHub Pages
Repo → Settings → Pages → Deploy from branch → `main` / root.

Note: the contact and careers forms prepare the message for the visitor to copy; connecting them to email is the next step.
